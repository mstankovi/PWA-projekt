# Newsweek web-portal

Statična prva faza projekta za predmet Programiranje web aplikacija. Projekt sadrži responzivnu naslovnicu i pojedinačni prikaz članka izrađene pomoću HTML-a i vanjskog CSS-a.

## Upute za pokretanje prve faze

1. Preuzmite ili klonirajte projekt.
2. Otvorite datoteku `index.html` u web-pregledniku.
3. Klikom na naslov vijesti otvorit će se stranica `clanak.html`.

Za ovu fazu nisu potrebni XAMPP, PHP ni baza podataka.

## Upute za pokretanje druge faze

1. Kopirajte projekt u XAMPP direktorij `htdocs`.
2. Pokrenite Apache servis u XAMPP Control Panelu.
3. U pregledniku otvorite `http://localhost/PWA%20Web%20App/unos.html` ili URL koji odgovara nazivu mape projekta.
4. Ispunite sva polja, odaberite JPEG, PNG ili WebP sliku do 5 MB i kliknite **Prihvati**.
5. PHP skripta prikazat će unesenu vijest u obliku pojedinačnog članka.

Za drugu fazu potrebni su Apache i PHP. MySQL baza još se ne koristi. Prenesene slike spremaju se u `assets/uploads`.
